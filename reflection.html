Professional reflection

What I have learned

During this module I learned how to plan, build and publish a professional website. I practised writing structured HTML, styling pages with CSS, making a layout work on both desktop and mobile, and using GitHub to store and publish my work. I also learned that a good website is about more than code: clear headings, descriptive links, meaningful page titles and image descriptions make a site easier for people and search engines to understand.

My strongest professional skill

My strongest skill is problem solving. When something does not work, I break it into smaller parts, test each one and search for reliable documentation until I find the cause. This approach helped me fix layout and link errors while building this portfolio.

A skill I want to improve

I would like to improve my JavaScript and my confidence in writing larger programs. At the moment I am comfortable with small exercises, but I want to be able to design and build complete applications with clean, well-organised code.

How I will develop it

I will set aside regular practice time each week and build small projects, such as a to-do list or a simple quiz app, and publish them on GitHub. I will follow online tutorials, read the documentation, and ask my lecturers and classmates for feedback on my code. Each finished project will teach me something new and can be added to this portfolio.

How this portfolio supports my future

This portfolio gives employers and lecturers a single place to see who I am, what I have built and how I am growing. I plan to keep it updated with new projects, certifications and experience throughout my studies. By graduation it should show a clear record of my skills, and it will support my applications for internships and my first job in IT.
